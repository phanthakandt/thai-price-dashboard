# ราคาวันนี้ — ไทยเทียบโลก

เว็บที่รวมราคา ทอง น้ำมัน ค่าเงิน หุ้น และเงินเฟ้อไว้ในหน้าเดียว ทุกตัวเลขแปลงเป็นเงินบาท เพื่อเทียบราคาไทยกับราคาโลกได้ตรง ๆ
ใช้แหล่งข้อมูลฟรีทั้งหมด ไม่ต้องสมัครหรือใช้ API key และไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## วิธีรัน

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป

```bash
node server.js            # ใช้ข้อมูลจริง แล้วเปิด http://localhost:3000
MOCK=1 node server.js     # ใช้ข้อมูลสมมติ สำหรับทดลองหน้าตาโดยไม่ต่อเน็ต
PORT=8080 node server.js  # เปลี่ยนพอร์ต
```

บน Windows (PowerShell) ให้ใช้ `$env:MOCK=1; node server.js`

## สัญญาณทิศทาง (ส่วนบนสุดของหน้า)

หลักคิดคือ ราคาไทยมักปรับตามราคาโลกที่เปลี่ยนไปแล้ว เว็บจึงดูว่า **ตั้งแต่ไทยปรับราคาครั้งล่าสุด ราคาโลก (แปลงเป็นบาทแล้ว) เปลี่ยนไปเท่าไร** ตัวเลขนั้นคือขนาดคร่าว ๆ ที่ราคาไทยน่าจะต้องปรับตาม

- **น้ำมัน:** ใช้โครงสร้างราคารายวันของ สนพ. (ราคาเนื้อน้ำมัน ณ โรงกลั่น, ภาษี, กองทุนน้ำมัน, ค่าการตลาด)
  ข้อมูลจริงพบว่าค่าการตลาดแทบคงที่ เมื่อต้นทุนขยับ กองทุนน้ำมันรับส่วนต่างไว้ก่อน แล้วราคาขายปลีกจะปรับเป็นขั้น (0.5–1 บาท)
  แรงกดดัน = [ราคาเนื้อน้ำมันที่เปลี่ยนไปตั้งแต่ปรับราคาครั้งล่าสุด + ภาระที่กองทุนอุดหนุนอยู่] × 1.07
  (การขยับของตลาดโลกหลังวันที่ของไฟล์ สนพ. ประมาณจาก RBOB/ULSD)
  ทดสอบย้อนหลัง ก.ค.–พ.ย. 2569: ทิศทางตรง 86% ของการปรับแก๊สโซฮอล์ 95 (12/14) และ 73% ของดีเซล (8/11)
  แต่บอกช่วงเวลาได้ไม่ดี ทุกการ์ดแสดงผลทดสอบย้อนหลังล่าสุดให้ดูเอง
- **ทอง:** API ของสมาคมฯ บอกว่าประกาศครั้งล่าสุดอิงราคาทองโลกและค่าเงินเท่าไร
  ราคาที่ราคาโลกชี้ = ราคาขายล่าสุด × (Gold Spot ตอนนี้ ÷ Gold Spot ที่อ้างอิง) × (ค่าเงินตอนนี้ ÷ ค่าเงินที่อ้างอิง)
  หน้าเว็บดึง Gold Spot ใหม่ทุก 1 นาทีขณะเปิดอยู่ และบันทึกความแม่นของสัญญาณไว้ตรวจย้อนหลัง
- **หุ้น:** ตัวชี้นำ 7 ตัว (S&P 500/Nasdaq ฟิวเจอร์ส, Nikkei, Hang Seng, VIX, ดัชนีดอลลาร์, บอนด์สหรัฐ 10 ปี) รวมเป็นคะแนนบรรยากาศตลาด
- **ข่าว:** หัวข้อข่าวล่าสุดจาก Google News แยก 4 หมวด
- **การว่างงาน:** รายไตรมาสจาก ILOSTAT (ไทย มาเลเซีย เวียดนาม ฟิลิปปินส์ สหรัฐ ญี่ปุ่น) และรายปีจาก World Bank เทียบค่าเฉลี่ยโลก
- **อาชีพ:** คนทำงานแยก 9 กลุ่มอาชีพ (ISCO-08) และ 21 ภาคธุรกิจ (ISIC) รายไตรมาสจาก ILOSTAT เทียบไตรมาสเดียวกันปีก่อน

**ต้องเปิดเซิร์ฟเวอร์ทิ้งไว้** เพราะแหล่งข้อมูลไทยฟรีให้แค่ราคาปัจจุบัน ระบบจึงบันทึกประวัติเองลงไฟล์ `data/history.json`
(ทองบันทึกทุก 2 นาที น้ำมันบันทึกวันละครั้ง) สัญญาณทองใช้ได้หลังเปิดเซิร์ฟเวอร์ไม่กี่นาที ส่วนสัญญาณน้ำมันจะแม่นขึ้นเมื่อบันทึกได้จนเห็นการปรับราคาของไทยอย่างน้อยหนึ่งครั้ง
ระหว่างที่ยังไม่มีประวัติ ระบบจะใช้การเปลี่ยนแปลงของราคาโลกในช่วง 3 วันแทน

**ข้อจำกัด:** ราคาน้ำมันไทยอิงตลาดสิงคโปร์ (MOPS) ซึ่งไม่มีข้อมูลฟรี ราคานิวยอร์กที่ใช้แทนมักเคลื่อนไหวทิศทางเดียวกันแต่ไม่ตรงทุกสตางค์
นอกจากนี้ ราคาดีเซลอาจถูกตรึงโดยกองทุนน้ำมันเชื้อเพลิง จึงอาจไม่ปรับตามตลาดโลก ตัวเลขทั้งหมดใช้ดูทิศทาง ไม่ใช่การพยากรณ์

## แหล่งข้อมูลและการเทียบ

| หมวด | ฝั่งไทย | ฝั่งโลก | วิธีเทียบ |
|---|---|---|---|
| ทอง | สมาคมค้าทองคำ (อ่านจากหน้าเว็บ) | gold-api.com (XAU/USD) | แปลงราคาโลกเป็น บาท/ทอง 1 บาท (15.244 กรัม, 96.5%) แล้วคิดส่วนต่างเป็น % |
| น้ำมัน | API ราคาน้ำมันของบางจาก | Brent, WTI จาก Yahoo Finance | แปลง USD/บาร์เรล เป็น บาท/ลิตร (1 บาร์เรล = 158.99 ลิตร) |
| ค่าเงิน | Frankfurter (อัตราอ้างอิงธนาคารกลาง) | – | บาทต่อ USD, EUR, GBP, CNY, 100 JPY และกราฟ USD/THB 1 ปี |
| หุ้น | SET (Yahoo Finance) | S&P 500, MSCI World (ETF URTH) | ผลตอบแทน 1 ปีคิดเป็นบาท (รวมผลของค่าเงินแล้ว) |
| เงินเฟ้อ | World Bank (ไทย, รายปี) | World Bank (ค่าเฉลี่ยโลก) | กราฟเทียบรายปี |

ระบบเก็บข้อมูลพักไว้ (cache) ตามความถี่ของแต่ละแหล่ง ได้แก่ ทอง 5 นาที, หุ้น/น้ำมันดิบ 15 นาที, ค่าเงินและน้ำมันไทย 1 ชั่วโมง, เงินเฟ้อ 1 วัน
ถ้าแหล่งใดดึงไม่สำเร็จ ระบบจะใช้ค่าล่าสุดที่มีอยู่และขึ้นข้อความเตือนเฉพาะการ์ดนั้น การ์ดอื่นยังทำงานตามปกติ

## ข้อควรรู้

- **ราคาทองไทย** ไม่มี API ทางการ จึงต้องอ่านจากหน้าเว็บสมาคมค้าทองคำ ถ้าสมาคมเปลี่ยนหน้าเว็บ ให้แก้ฟังก์ชัน `fetchThaiGold` ใน `sources.js`
- **Yahoo Finance** ใช้ได้ฟรีแต่ไม่เป็นทางการ ข้อมูลดีเลย์ราว 15–20 นาที และอาจเปลี่ยนรูปแบบหรือบล็อกได้ ถ้าจะเปิดเป็นเว็บสาธารณะเชิงพาณิชย์ ควรใช้ข้อมูลที่มีสิทธิ์เผยแพร่ เช่น ข้อมูลจาก SET
- **เงินเฟ้อรายเดือนและดอกเบี้ยนโยบาย** ยังไม่ได้ใส่ เพราะ BOT API Portal ต้องสมัครรับ key (ฟรี) ถ้าได้ key แล้ว ให้เก็บใน GitHub Secrets แล้วเพิ่มฟังก์ชันใน `sources.js`
- **เว็บตลาดหลักทรัพย์ฯ** บล็อกเซิร์ฟเวอร์ของ GitHub ประวัติ SET จึงเริ่มจากไฟล์ `seed/set-history.csv` แล้วบันทึกต่อเองทุกวัน
- ก่อนดึงข้อมูลจากเว็บใดเป็นประจำ ควรตรวจเงื่อนไขการใช้งานของเว็บนั้น

## โครงสร้างไฟล์

```
server.js        เว็บเซิร์ฟเวอร์สำหรับรันเอง (GET /data.json)
lib/build.js     ตรรกะหลัก: เทียบราคาและคำนวณสัญญาณทิศทาง
lib/history.js   บันทึกประวัติราคาไทย
scripts/build-data.mjs  สร้างเว็บ static สำหรับ GitHub Pages
.github/workflows/update.yml  ตั้งเวลาอัปเดตทุก 15 นาที
sources.js       ฟังก์ชันดึงข้อมูลจากแต่ละแหล่ง
mock.js          ข้อมูลสมมติสำหรับทดสอบ
public/index.html  หน้าเว็บ (รองรับโหมดมืด, มือถือ)
```

## GitHub Pages (อัปเดตอัตโนมัติ)

ไฟล์ `.github/workflows/update.yml` สั่งให้ GitHub Actions รัน `scripts/build-data.mjs` ทุก 15 นาที
สคริปต์จะดึงราคาใหม่ โหลดประวัติราคาจากเว็บที่ deploy ไว้รอบก่อนมาบันทึกต่อ แล้ว deploy หน้าเว็บกับไฟล์ `data.json` ขึ้น Pages
ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

- เปิดใช้: Settings → Pages → Source เลือก **GitHub Actions**
- สั่งอัปเดตทันที: แท็บ Actions → Update prices → Run workflow
- GitHub อาจเลื่อนเวลารันตามรอบออกไปบ้างในช่วงที่มีคนใช้เยอะ
- ถ้า repo ไม่มีความเคลื่อนไหว (commit) นาน 60 วัน GitHub จะหยุดรันตามรอบ ให้กด Enable workflow ในแท็บ Actions เพื่อเปิดใหม่

## นำขึ้นออนไลน์แบบมีเซิร์ฟเวอร์

โปรเจกต์ไม่มี dependency จึงนำไปรันบนบริการที่รองรับ Node.js ได้เกือบทุกที่ เช่น Render, Railway, Fly.io หรือ VPS
ใช้คำสั่งเริ่มต้นเป็น `node server.js` และบริการเหล่านี้จะกำหนด `PORT` ให้เอง
